- `databricks.svg`: https://cdn.simpleicons.org/databricks
- `mlflow.svg`: https://cdn.simpleicons.org/mlflow
- `huggingface.svg`: https://cdn.simpleicons.org/huggingface

The SVGs are served from this repository, so the website does not depend on the
CDN at runtime. Existing PNG assets are not part of this download.
